# Sito di Serena Ionta

Sito statico pronto per GitHub Pages.

## File
- `index.html` — Home
- `research.html` — Research
- `cv.html` — CV
- `teaching.html` — Teaching
- `miscellanea.html` — Miscellanea
- `style.css` — grafica di tutte le pagine
- `theme.js` — pulsante giorno / notte

## Come pubblicarlo
1. Carica tutti i file nella repository `iontaserena.github.io`
2. Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`
3. Il sito compare su https://iontaserena.github.io

## Immagini
- `photo.jpg` — foto della Home
- `book.jpg` — copertina del libro (Miscellanea)

Dopo averle caricate, nel file HTML cancella il blocco
`<div class="foto-segnaposto">…</div>` e togli i commenti attorno al tag `<img>`.

## CV in PDF
Carica il file con il nome esatto `cv.pdf`: il link nella pagina CV funzionerà da solo.
